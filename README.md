# xoibot

Бот для управления подключениями к xui панели
Telegram bot for managing xui panel with inline keyboard support, user access requests, and anti-flood protection
## Установка

```bash
git clone https://github.com/ваш-проект/3xui-bot.git
cd 3xui-bot
cp .env.example .env
# Отредактируйте .env
docker-compose up -d
